# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not file a public issue.

Please report vulnerabilities privately by contacting the project maintainers or creating a private security advisory on GitHub.

When reporting a vulnerability, please include:
- A description of the issue and potential impact
- Steps to reproduce or a proof of concept
- Suggested mitigations (if available)

All security reports will be acknowledged promptly and investigated thoroughly.
